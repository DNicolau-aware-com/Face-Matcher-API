# Workers Comparison — test1m Gallery (41K faces)

| Metric | 16 Workers | 1 Worker |
|--------|-----------|---------|
| Avg latency | 15,690 ms | **2,432 ms** |
| P95 latency | 16,804 ms | **2,580 ms** |
| P99 latency | 17,242 ms | **2,716 ms** |

| Errors | 0 | 0 |
| Rank-1 accuracy | 95.62% | 95.62% |
| Production pass | NO (latency) | **YES** |

> **Key finding:** 16 concurrent workers saturate the demo server, inflating latency from ~2.4s to ~15.7s with no accuracy gain. 1 worker produces clean, production-representative latency at the cost of longer total run time. Accuracy is identical regardless of worker count.
